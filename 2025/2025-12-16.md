#### 4. Special Topic: Gift Exchange - Maintainer Tips and Tools

Share a cool trick, tip or tool that you use frequently and makes your life as a maintainer easier.

##### Discussion:

- Meeting 1:
    - Add suggestions directly to a GH pull request. This way the change is made (commited) directly if accepted, and the reviewer doesn't have to make change themselves. 
    - Readme file to keep track of what we are doing as maintainers.
    - Ask people who open issues how would they solve the issue, and maybe they already have solved it on a fork of their own.

- Meeting 2:
    - Meeting with your fellow maintainers. Taking some decisions is way faster when we meet, easir to move forward.
    - Block at least one day a month to talk about the lesson with co-maintainers, and have a document keeping track of stuff.
    - Open PRs and tag co-Maintainers to review.
    - Get a LOT of emails from GH. To know what notifications are more relevant (mentions, request for review) use the emails GH uses as CC and set up the email client to filter these.
    - GH mobile app also works great! Even for doing actual work like PRs.
    - GitHub milestones.
    - Anyone using Git merge tools? VS Code has a tool for working on conflicts, looking at both versions side by side is very useful. GitHub UI is also useful.
    - VS Code extension - Text files.
